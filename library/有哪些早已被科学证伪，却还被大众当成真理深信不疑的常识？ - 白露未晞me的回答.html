有哪些早已被科学证伪，却还被大众当成真理深信不疑的常识？

讲几个专业相关的吧，部分内容可能有争议，觉得有异议的话可以评论区一起理性讨论。

BatchNorm 有效，是因为它减少了 Internal Covariate Shift ❌

BatchNorm 原论文把效果很大程度归因于：前层不断更新导致后层输入分布变化，BN 稳定这种 distribution shift。这个故事非常直观，于是传播得极广。

但 Santurkar 等人在 NeurIPS 2018 直接做实验发现：你甚至可以人为制造严重的 distribution shift，同时保留 BatchNorm 的训练收益。他们认为其重要作用更接近于改善优化几何，使梯度更加稳定、loss landscape 更平滑。虽然后续对 BN 的精确机制仍有讨论，但至少BN 工作的原因就是消除 internal covariate shift个人认为已经不能再当成事实讲了，但是你在知乎上仍然可以刷到大量所谓科普博主直到今年还在坚持直接翻译BN原论文来解释各种normalization为何work。

神经网络输出 90% confidence，就意味着它大约有 90% 概率是对的 ❌

这是我多年前就很喜欢的一个结论，可惜一直没能围绕它做一些自己真正感兴趣的工作。

具体来说，我们平时看到一个分类网络输出“猫：90%”，很容易顺手把它理解成：模型认为这张图有 90% 的概率是一只猫。这个解释非常自然，甚至很多入门材料也会这样讲，但神经网络给出的 confidence 通常没有这么可靠。

举个简单的例子。假设我们把所有 confidence 在 90% 左右的预测收集起来，一共有 1000 个。如果这些预测最后真的有大约 900 个正确，那么模型在这一档 confidence 上就是校准良好的。现实里的深度神经网络经常做不到这一点，它可能对这 1000 个样本都表现得非常自信，真正预测正确的却只有七八百个。模型说出的“90%”因此更多是在描述 softmax 输出的大小，并没有天然携带“现实中有九成概率正确”这样的统计含义。

这件事有意思的地方在于，模型准确率继续提高时，confidence 的可信程度甚至可能变差。Guo 等人在 2017 年系统研究过这个问题，他们发现现代深层网络往往存在明显的 overconfidence，而且网络变得更深、更宽、训练得更充分以后，这种现象依然可能出现。

所以机器学习里后来专门有了 calibration 这一套东西。我们关心的不再只有“模型猜对了多少”，还会问另一件事：模型到底知不知道自己有多大把握？一个 80% 准确率、同时知道自己什么时候可能出错的模型，在医疗、自动驾驶、风险判断这些场景里，有时会比一个 85% 准确率、却动不动给出 99.9% confidence 的模型更有价值。

Classification error 已经变成 0 以后，再训练只是浪费时间 ❌

这也是我很多年前第一次看到时觉得特别漂亮的一个结论：一个分类器在训练集上已经 100% 正确以后，继续训练仍然可能在做非常重要的事情。

最干净的例子来自线性可分数据上的 logistic regression。假设存在某个 ，能够让所有训练样本满足 。训练一段时间后，classification error 很快就会变成 0，此后无论再训练多久，每个样本看起来都已经“分对了”。按很自然的直觉，这时候优化基本应该结束了。

然而 Soudry 等人在 2018 年证明了一件很有意思的事情：如果继续用 gradient descent 优化 logistic loss，参数并不会收敛到某个有限的 。它的模长会越来越大： 但参数的方向却会逐渐稳定下来，而且最终趋近于 hard-margin SVM 的方向：

换句话说，训练准确率早已经是 100%，模型依然在悄悄移动决策边界，让离边界最近的那些样本拥有越来越大的 margin。更有趣的是，整个过程中 loss 还能从 一直降到 ，虽然表面上的分类结果一个都没有变化。

这件事后来又被推广到了更接近神经网络的情形。Lyu 和 Li 研究了 ReLU、Leaky-ReLU 等 homogeneous neural networks，发现用 gradient descent/gradient flow 优化 logistic 或 cross-entropy loss 时，在一定条件下 normalized margin 也会持续增加，并最终趋向相应 margin optimization 问题的 KKT 点。

Attention Weight就是模型认为这个token有多重要 ❌

这个误解也很常见，因为 attention map 实在太像一张现成的“重要性热力图”了。比如模型处理一句话时，某个 head 给 “cat” 的 attention 是 0.8，给 “dog” 只有 0.1，我们很容易顺手解释成：模型觉得 cat 比 dog 重要八倍。但从计算上看，这个数字其实只表示，在当前这一层、这个 attention head、这个 query 下，模型用多大的系数去混合对应位置的 value vector。它并没有直接回答“如果删掉这个词，最终预测会发生多大变化”。

这里有一个很关键的区别。假设两个 token 的 attention 分别是 0.8 和 0.2，但第二个 token 对应的 value vector 恰好携带着决定分类方向的信息，那么它虽然权重很小，对最终输出却可能更加关键。更何况 Transformer 后面还有多个 attention head、残差连接、MLP、几十层甚至上百层计算，一个 token 的信息也可以先写进别的位置，再间接影响最终答案。所以单独看某一张 attention map，本来就很难把整个网络的因果路径压缩成“这个词贡献了多少”。

这件事在 2019 年曾经引起过一轮很有意思的争论。Jain 和 Wallace 的 Attention is not Explanation 做了一个非常直接的实验：他们发现 attention weight 和 gradient-based feature importance 经常相关性很低，而且甚至能构造出差异非常大的 attention 分布，却得到几乎一样的预测结果。Serrano 和 Smith 从另一个角度直接修改、删除高 attention 的成分，也发现 attention 大小并不能稳定预测这些修改对输出的影响。

因此，个人认为更准确的说法应该是：attention 是一种很有价值的内部观测信号，但普通 attention weight 本身并不是模型决策重要性的可靠因果解释。

Ablation一个组件后性能下降多少，就能准确衡量这个组件的重要性❌

这个问题主要在于，ablation 测到的不一定是某个组件原本的“贡献大小”。

直觉上，我们把一个 attention head 或某一层删掉，如果性能只下降 2%，就会觉得它大概只贡献了 2%。但 Transformer 不是几个互不影响的模块简单相加。前面的组件被拿掉以后，残差流和后续层收到的输入都会发生变化，后面的 attention、MLP 也会跟着产生不同的输出，有时甚至会把缺掉的那部分功能补回来。

McGrath 等人在 2023 年把这种现象称为 Hydra Effect。他们在语言模型的 factual recall 实验中发现，ablate 某个 attention layer 后，一些后续 layer 对正确答案的贡献反而会上升，抵消掉相当一部分损失。更有意思的是，这个过程完全不需要重新训练，模型参数一个都没变，只是一次 forward pass 里后续组件的响应发生了变化。

所以“删掉以后性能下降多少”不能直接当成“这个组件有多重要”。如果网络内部存在 redundancy 或 self-repair，一个原本很重要的组件被删掉后，也可能因为其他组件及时顶上来，看起来几乎没造成什么影响。

深度网络训练困难，主要是因为掉进了坏的local minima ❌

这个直觉其实来自我们对二维曲面的想象：训练就像一个小球沿着山坡往下滚，只要掉进一个位置不够低的坑里，梯度变成 0，它就再也爬不出来了。所以早期讲神经网络优化时，“local minima 太多”经常被当成深度网络难训练的主要原因。但到了真正的高维网络里，这幅图往往并不太对。

原因之一很简单：高维空间里的 stationary point，大多数未必是“坑”。 假设一个网络有几百万个参数，一个点要成为严格的 local minimum，就要求 Hessian 在几百万个方向上基本都向上弯。只要其中还有某个方向能够继续下降，它就更接近 saddle point。Dauphin 等人在 2014 年专门研究过这个问题，提出在高维非凸优化中，真正大量出现并拖慢训练的可能是 saddle points 以及附近非常平坦的平台，而不是一堆把优化器彻底困住的坏 local minima。

比如你走到某个位置，前后左右看起来几乎都是平的，梯度小得接近 0，于是训练半天 loss 都不怎么动。二维图上它很像“掉进坑里了”，但实际上可能存在一个极不起眼的方向仍然可以继续往下走。参数维度越高，这种“绝大多数方向很平，少数方向还能下降”的情况反而越自然。

更反直觉的是，即使两次训练最后得到两个参数完全不同的 minimum，它们也未必位于两个互不相干的山谷。Draxler 等人在 CIFAR-10/100 上发现，不同训练得到的 minima 之间，可以构造一条 loss 几乎不升高的连续路径。也就是说，我们平时二维 loss landscape 里看到的“两座独立山谷”，在真正的几百万维空间里，可能绕一个我们没画出来的方向就连起来了。

Anyway，所以训练困难更准确的原因应当是saddle point、近零曲率区域、ill-conditioning，以及非常复杂的高维几何结构。

训练误差为0，就说明模型只是把数据背下来了，所以不可能泛化 ❌

import csv, math
from pathlib import Path
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from PIL import Image
from numba import njit

TOTAL_STEPS = 10_000_000
LR = 0.07
OUT = Path(__file__).resolve().parent
GIF = OUT / "zero_error_margin_demo.gif"
HISTORY = OUT / "training_history.csv"
DATA = OUT / "dataset.csv"
PREVIEW = OUT / "final_frame.png"


def make_data():
    z = []
    for a in np.linspace(0, 20, 8):
        for _ in range(4):
            t = np.deg2rad(a)
            z.append([8*np.cos(t), 8*np.sin(t)])
    for a in [30, 40, 50]:
        t = np.deg2rad(a)
        z.append([3*np.cos(t), 3*np.sin(t)])
    for a in [55, 105]:
        t = np.deg2rad(a)
        z.append([np.cos(t), np.sin(t)])

    z = np.asarray(z, dtype=np.float64)
    X = np.vstack([z, -z])
    y = np.r_[np.ones(len(z)), -np.ones(len(z))]
    return X, y, z


def hard_margin_svm_2d(z):
    candidates = [zi / np.dot(zi, zi) for zi in z]
    for i in range(len(z)):
        for j in range(i + 1, len(z)):
            A = np.vstack([z[i], z[j]])
            if abs(np.linalg.det(A)) > 1e-12:
                candidates.append(np.linalg.solve(A, np.ones(2)))

    best = None
    for w in candidates:
        if np.min(z @ w) >= 1 - 1e-9:
            n = np.linalg.norm(w)
            if best is None or n < best[0]:
                best = (n, w)

    norm, w = best
    u = w / norm
    return w, u, 1/norm, np.degrees(np.arctan2(u[1], u[0]))


@njit
def train(z, record_steps, total_steps, lr):
    n = len(z)
    out = np.zeros((len(record_steps), 9))
    w0 = w1 = 0.0
    ri = 0

    for step in range(1, total_steps + 1):
        g0 = g1 = 0.0

        for i in range(n):
            m = z[i, 0]*w0 + z[i, 1]*w1
            if m >= 0:
                e = math.exp(-m)
                s = e / (1 + e)
            else:
                e = math.exp(m)
                s = 1 / (1 + e)

            g0 -= z[i, 0]*s/n
            g1 -= z[i, 1]*s/n

        w0 -= lr*g0
        w1 -= lr*g1

        if ri < len(record_steps) and step == record_steps[ri]:
            norm = math.sqrt(w0*w0 + w1*w1)
            loss = 0.0
            correct = 0
            raw_min = 1e300

            for i in range(n):
                m = z[i, 0]*w0 + z[i, 1]*w1
                raw_min = min(raw_min, m)
                correct += m > 0

                if -m > 0:
                    loss += -m + math.log1p(math.exp(m))
                else:
                    loss += math.log1p(math.exp(-m))

            out[ri, 0] = step
            out[ri, 1] = w0
            out[ri, 2] = w1
            out[ri, 3] = loss/n
            out[ri, 4] = correct/n
            out[ri, 5] = norm
            out[ri, 6] = raw_min
            out[ri, 7] = raw_min/norm
            out[ri, 8] = math.degrees(math.atan2(w1, w0))
            ri += 1

    return out


def boundary(w, span=10, offset=0):
    u = w / np.linalg.norm(w)
    d = np.array([-u[1], u[0]])
    p = offset*u
    t = np.array([-span, span])
    xy = p[:, None] + d[:, None]*t
    return xy[0], xy[1]


def canvas(fig):
    fig.canvas.draw()
    a = np.asarray(fig.canvas.buffer_rgba())[:, :, :3]
    return Image.fromarray(a.copy())


def main():
    X, y, z = make_data()
    svm_w, svm_u, svm_margin, svm_angle = hard_margin_svm_2d(z)

    anim_steps = np.unique(np.r_[
        np.arange(1, 31, 2),
        np.geomspace(31, TOTAL_STEPS, 42).astype(np.int64),
        TOTAL_STEPS
    ]).astype(np.int64)

    record_steps = np.unique(np.r_[
        np.arange(1, 301),
        np.geomspace(300, TOTAL_STEPS, 900).astype(np.int64),
        anim_steps, TOTAL_STEPS
    ]).astype(np.int64)

    h = train(z, record_steps, TOTAL_STEPS, LR)

    first = h[np.where(h[:, 4] >= 1.0)[0][0]]
    final = h[-1]

    with DATA.open("w", newline="", encoding="utf-8") as f:
        w = csv.writer(f)
        w.writerow(["x1", "x2", "label"])
        for xi, yi in zip(X, y):
            w.writerow([xi[0], xi[1], int(yi)])

    with HISTORY.open("w", newline="", encoding="utf-8") as f:
        w = csv.writer(f)
        w.writerow([
            "step","w1","w2","loss","accuracy","weight_norm","raw_min_margin",
            "normalized_margin","weight_angle_deg","svm_normalized_margin",
            "svm_angle_deg","angle_gap_deg"
        ])
        for r in h:
            w.writerow([int(r[0]), *r[1:], svm_margin, svm_angle, abs(r[8]-svm_angle)])

    step_to_idx = {int(s): i for i, s in enumerate(h[:, 0])}
    ids = [step_to_idx[int(s)] for s in anim_steps]

    # Each chart is a separate figure; the rendered images are stitched into one GIF frame.
    fb, ab = plt.subplots(figsize=(5.6, 5.6), dpi=90)
    pos = y > 0
    ab.scatter(X[pos,0], X[pos,1], s=22, label="+1")
    ab.scatter(X[~pos,0], X[~pos,1], s=22, marker="^", label="-1")
    support = np.isclose(y*(X @ svm_w), 1.0, atol=1e-7)
    ab.scatter(X[support,0], X[support,1], s=55, marker="s", label="SVM support")

    cur, = ab.plot([], [], linewidth=2.0, label="GD boundary")
    sx, sy = boundary(svm_w)
    ab.plot(sx, sy, "--", linewidth=1.8, label="hard-margin SVM")

    smx1, smy1 = boundary(svm_u, offset=svm_margin)
    smx2, smy2 = boundary(svm_u, offset=-svm_margin)
    ab.plot(smx1, smy1, ":", linewidth=1.0)
    ab.plot(smx2, smy2, ":", linewidth=1.0)

    cm1, = ab.plot([], [], ":", linewidth=0.9)
    cm2, = ab.plot([], [], ":", linewidth=0.9)
    info = ab.text(0.03, 0.03, "", transform=ab.transAxes, va="bottom",
                   family="monospace", fontsize=8,
                   bbox=dict(boxstyle="round", alpha=0.75))
    ab.set(xlim=(-9.5,9.5), ylim=(-9.5,9.5), xlabel="x1", ylabel="x2")
    ab.set_aspect("equal", adjustable="box")
    ab.legend(loc="upper right", fontsize=7)
    ab.set_title("Accuracy can be 100% while the boundary still moves", fontsize=10)
    fb.tight_layout()

    fl, al = plt.subplots(figsize=(4.2,1.8), dpi=90)
    ll, = al.plot([], [], linewidth=1.6)
    ld, = al.plot([], [], marker="o")
    al.set_xscale("log"); al.set_yscale("log")
    al.set_xlim(1, TOTAL_STEPS)
    al.set_ylim(max(h[:,3].min()*0.6, 1e-12), h[:,3].max()*1.4)
    al.set_ylabel("logistic loss")
    al.grid(alpha=0.2)
    fl.tight_layout()

    fa, aa = plt.subplots(figsize=(4.2,1.8), dpi=90)
    la, = aa.plot([], [], linewidth=1.6)
    ad, = aa.plot([], [], marker="o")
    aa.set_xscale("log"); aa.set_xlim(1, TOTAL_STEPS); aa.set_ylim(0.94, 1.005)
    aa.set_ylabel("accuracy")
    aa.grid(alpha=0.2)
    fa.tight_layout()

    fm, am = plt.subplots(figsize=(4.2,2.0), dpi=90)
    lm, = am.plot([], [], linewidth=1.6, label="GD margin")
    md, = am.plot([], [], marker="o")
    am.axhline(svm_margin, linestyle="--", linewidth=1.3, label="SVM max margin")
    am.set_xscale("log"); am.set_xlim(1, TOTAL_STEPS)
    am.set_ylim(-0.07, svm_margin*1.05)
    am.set_xlabel("gradient-descent step")
    am.set_ylabel("normalized margin")
    am.legend(loc="lower right", fontsize=7)
    am.grid(alpha=0.2)
    fm.tight_layout()

    frames = []
    for idx in ids:
        r = h[idx]
        step, w0, w1, loss, acc, norm, raw, margin, angle = r
        w = np.array([w0, w1])

        x, yy = boundary(w)
        cur.set_data(x, yy)

        if margin > 0:
            u = w/norm
            x1,y1 = boundary(u, offset=margin)
            x2,y2 = boundary(u, offset=-margin)
            cm1.set_data(x1,y1); cm2.set_data(x2,y2)
        else:
            cm1.set_data([],[]); cm2.set_data([],[])

        info.set_text(
            f"step: {int(step):,}\n"
            f"accuracy: {acc*100:6.2f}%\n"
            f"loss: {loss:.3e}\n"
            f"||w||: {norm:.3f}\n"
            f"margin: {margin:.4f}\n"
            f"SVM:    {svm_margin:.4f}\n"
            f"angle gap: {abs(angle-svm_angle):.2f} deg"
        )

        hh = h[:idx+1]
        ll.set_data(hh[:,0], hh[:,3]); ld.set_data([step],[loss])
        la.set_data(hh[:,0], hh[:,4]); ad.set_data([step],[acc])
        lm.set_data(hh[:,0], hh[:,7]); md.set_data([step],[margin])

        left = canvas(fb).resize((540,540), Image.Resampling.BILINEAR)
        r1 = canvas(fl).resize((360,170), Image.Resampling.BILINEAR)
        r2 = canvas(fa).resize((360,170), Image.Resampling.BILINEAR)
        r3 = canvas(fm).resize((360,200), Image.Resampling.BILINEAR)

        panel = Image.new("RGB", (900,540))
        panel.paste(left,(0,0))
        panel.paste(r1,(540,0))
        panel.paste(r2,(540,170))
        panel.paste(r3,(540,340))
        frames.append(panel)

    frames[-1].save(PREVIEW)

    duration = [90]*len(frames)
    duration[0] = 500
    duration[-1] = 2200
    frames[0].save(GIF, save_all=True, append_images=frames[1:],
                   duration=duration, loop=0, optimize=False)

    plt.close("all")

    print(f"First 100% accuracy: step {int(first[0])}")
    print(f"  loss              = {first[3]:.8g}")
