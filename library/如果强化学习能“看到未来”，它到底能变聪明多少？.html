如果强化学习能“看到未来”，它到底能变聪明多少？

这篇 NeurIPS 2025 的论文，算是我们前面那篇 ICML 工作的姊妹篇。

ICML 那篇关心的是：

高维强化学习太难学，能不能把大系统近似拆成几个小系统？

这篇 NeurIPS 论文关心的是另一个很自然的问题：

如果智能体能拿到未来几步的预测信息，它到底该怎么用？这些预测又到底值多少钱？

论文题目是：

Reinforcement Learning with Imperfect Transition Predictions: A Bellman-Jensen Approach

作者包括 Chenbei Lu @卢晨贝、Zaiwei Chen、Tongxin Li、我和 Adam Wierman。

一个很现实的场景：我们其实经常能“预测未来”

传统强化学习通常假设智能体只看到当前状态，然后根据环境的转移概率做决策。

但在很多真实问题里，我们其实并不是完全“盲打”。

比如能源系统里：

  • 明天的风电出力有预测；
  • 未来几小时的负荷有预测；
  • 电价有预测；
  • 天气有预测。

金融市场里也类似：

  • 价格趋势有预测；
  • 风险指标有预测；
  • 市场状态有预测。

这些预测不一定完美，但它们确实包含有用信息。

所以一个自然的问题是：

强化学习能不能把这些未来预测用起来，而不是只像传统 MDP 那样依赖一步转移概率？

听起来很简单：把预测直接放进状态里不就行了吗？

但问题来了。

直接把预测塞进状态，会发生什么？

假设智能体能看到未来 步预测。

看起来合理，但会带来一个非常严重的问题：

状态空间爆炸。

因为未来预测本身是高维的。
每一步预测可能包含多个状态、多个动作、多个转移结果。
如果预测 horizon 稍微长一点，增强后的状态空间就会变得巨大，甚至可能是连续的、无限维的。

这就又回到了强化学习的老问题：

维度灾难。

所以这篇论文要解决的第一个问题是：

能不能利用多步预测，但不显式扩展状态空间？

核心想法一： Bayesian Value Function

我们的做法是引入一个 Bayesian value function。

直观地说：

策略可以根据实时预测做决策，但价值函数仍然定义在原始状态空间上。

这句话很关键。

传统做法可能会把预测 和状态 拼成一个大状态 ，然后在这个巨大空间上求 value function。

但我们不这么做。

我们把预测的不确定性通过期望转化成“积分”（Loss或者Reward），让 value function 仍然只依赖原始状态 。
这样就避免了直接状态增强带来的维度爆炸。

简单理解：

  • 离线阶段：学一个长期的 Bayesian value function；
  • 在线阶段：拿到实时预测后，做一个短期 look-ahead planning；
  • 终点处再接上离线学到的长期 value。

这有点像：

平时先学会“长期判断力”（直觉），真正决策时再结合眼前的短期情况做调整。

核心想法二：Bellman-Jensen Gap

这篇论文里我觉得最有意思的概念是：

Bellman-Jensen Gap

它试图回答一个很基础的问题：

预测信息到底为什么有价值？

在传统 MDP 里，智能体做决策时面对的是“期望意义上的未来”。
也就是说，它通常是在不知道未来具体 realization（实现）的情况下，选择一个在平均意义上最好的动作。

一句话解释：

没有预测时，只能选一个平均意义上不错的动作；
有预测时，可以根据未来情况选择更合适的动作。

这种由 Bellman 递归结构中 max 和 expectation 重新排序带来的收益，我们称为 Bellman-Jensen Gap。

它刻画了预测信息相对于传统 MDP 的理论价值。

预测不完美怎么办？

当然，现实中的预测通常不完美。

这篇论文没有假设预测一定准确，而是考虑了三个更现实的因素：

  1. 预测 horizon 有限
    你不可能看到无限远的未来，只能看到未来 步。
  2. 预测有误差
    风电预测、电价预测、负荷预测都可能出错。
  3. 不是所有动作都可预测
    有些动作下的未来转移比较容易预测，有些动作下的结果很难预测。

论文里的一个主要理论结果，就是把“预测策略”和“离线全知最优策略”之间的差距拆成三部分：

  • 由于预测窗口有限带来的损失；
  • 由于预测误差带来的损失；
  • 由于只有部分动作可预测带来的损失。

这个分解很有解释性。

它告诉我们：

预测越长、越准、覆盖动作越多，智能体就越接近那个“知晓未来”的离线最优策略。

但即使预测不完美，只要它足够有用，也能带来性能提升。

核心算法：BOLA

基于前面的理论分析，我们提出了一个算法：

BOLA: Bayesian Offline Learning with Online Adaptation

名字有点长，但思路很清楚。

它分成两个阶段：

1. Offline learning

离线阶段，利用样本学习 Bayesian value function。

这个 value function 可以理解为长期决策的“底盘”（again，AI的直觉）。

2. Online adaptation

在线阶段，每次拿到未来 步预测后，做一个短期规划：

  • 看当前状态；
  • 看未来预测；
  • 规划未来 步动作；
  • 用离线学到的 Bayesian value function 作为 terminal value。

这样做的好处是：

在线不用在巨大预测增强状态空间上重新求解，只需要做轻量级短期规划。

这对实际系统很重要，因为预测是实时来的，决策也往往需要快速完成。

这和前面那篇 ICML 姊妹篇有什么关系？

我觉得这两篇论文其实是在回答同一个大问题：

如何让强化学习更适合真实复杂系统？

ICML 那篇的角度是：

高维系统通常有结构，可以近似分解，从而降低样本复杂度。

NeurIPS 这篇的角度是：

真实系统通常有预测信息，可以利用未来预测提升决策性能。

一个利用的是系统结构，一个利用的是未来信息。

它们都不是把强化学习当成一个黑箱神经网络直接套上去，而是问：

  • 系统有没有结构？
  • 预测有没有价值？
  • 这些信息如何进入 Bellman 方程？
  • 误差和样本复杂度能不能分析清楚？

这也是我们组比较感兴趣的一类问题：

让机器学习、优化理论和能源系统运行真正结合起来。

我觉得这篇论文有意思的地方

这篇论文最吸引我的地方，不是简单地说“预测能提升性能”。

这件事大家直觉上都相信。

更重要的是，它试图回答：

预测为什么有价值？
不完美预测还能有多少价值？
如何在不引入维度灾难的情况下使用多步预测？
学这个 prediction-aware value function 需要多少样本？

这些问题对于真实系统非常重要。

因为在能源系统、金融系统、交通系统里，我们从来不是没有预测。
真正的问题是：

预测很有用，但也有误差；
预测能帮助决策，但不能让状态空间爆炸；
我们需要算法，也需要理论告诉我们什么时候值得相信预测。

一句话总结

这篇论文想说的是：

强化学习不应该只在“没有未来信息”的传统 MDP 里做决策。
当未来预测可用时，即使预测不完美，也可以通过 Bayesian value function 和 Bellman-Jensen Gap 理论，把这些预测以可计算、可分析的方式融入决策。
