## Measure and Measurability
::: definition:$\sigma$-Algebra
Let $X$ be a set and $\mathcal{M} \subseteq \mathcal{P}(X)$. The family $\mathcal{M}$ is a $\sigma$-algebra on $X$ if:
- $X \in \mathcal{M}$.
- $X \setminus A \in \mathcal{M}$ for any $A \in \mathcal{M}$.
- $\bigcup_{n = 1}^{\infty} A_n \in \mathcal{M}$ for any sequence $(A_n)_{n \geq 1}$ in $\mathcal{M}$.
The pair $(X, \mathcal{M})$ is a measurable space.
:::

::: definition:Measurable Set
Let $(X, \mathcal{M})$ be a measurable space. A subset $E \subseteq X$ is measurable if $E \in \mathcal{M}$.
:::

::: definition:Borel Set
Let $X$ be a topological space. The Borel $\sigma$-algebra $\mathcal{B}(X)$ is the $\sigma$-algebra generated by the open sets of $X$. A subset of $X$ is a Borel set if it belongs to $\mathcal{B}(X)$.
:::

::: definition:Measure
Let $(X, \mathcal{M})$ be a measurable space and $\mu : \mathcal{M} \to [0, \infty]$. The map $\mu$ is a measure if:
- $\mu(\emptyset) = 0$.
- $\mu(\bigcup_{n = 1}^{\infty} A_n) = \sum_{n = 1}^{\infty}\mu(A_n)$ for any sequence of pairwise disjoint sets $A_n \in \mathcal{M}$.
The triple $(X, \mathcal{M}, \mu)$ is a measure space.
:::

::: definition:Sigma-Finite Measure
Let $(X, \mathcal{M}, \mu)$ be a measure space. The measure $\mu$ is $\sigma$-finite if there exists a sequence $(E_n)_{n \geq 1}$ in $\mathcal{M}$ s.t. $X = \bigcup_{n = 1}^{\infty}E_n$ and $\mu(E_n) < \infty$ for any $n \geq 1$.
:::

::: definition:Measurable Function
Let $(X, \mathcal{M})$ and $(Y, \mathcal{N})$ be measurable spaces and $f : X \to Y$. The function $f$ is measurable if $f^{-1}(E) \in \mathcal{M}$ for any $E \in \mathcal{N}$. When $Y$ is a topological space, measurability into $Y$ refers to $\mathcal{N} = \mathcal{B}(Y)$; equivalently, $f^{-1}(V) \in \mathcal{M}$ for any open $V \subseteq Y$.
:::

::: proposition
Let $(X, \mathcal{M})$ be a measurable space and $f : X \to Y$ be a map into a set $Y$. Set $\Omega = \{E \subseteq Y : f^{-1}(E) \in \mathcal{M}\}$. The family $\Omega$ is a $\sigma$-algebra on $Y$.
:::

::: note
The inverse-image condition defines a $\sigma$-algebra on the codomain without requiring the map to be surjective.
:::

::: proposition
Let $(X, \mathcal{M})$ be a measurable space and $f : X \to Y$ be a measurable map into a topological space $Y$. The preimage $f^{-1}(E)$ belongs to $\mathcal{M}$ for any $E \in \mathcal{B}(Y)$.
:::

::: note
For a measurable map into a topological space, this $\sigma$-algebra contains all Borel sets.
:::

::: proposition
Let $(X, \mathcal{M})$ be a measurable space and $f : X \to [-\infty, \infty]$. If $f^{-1}((\alpha, \infty]) \in \mathcal{M}$ for any $\alpha \in \mathbb{R}$, then $f$ is measurable with respect to the Borel $\sigma$-algebra of the extended real line.
:::

::: note
Measurability can be checked on a family of sets generating the target Borel $\sigma$-algebra.
:::

::: definition:Borel Measurable Function
Let $X$ and $Y$ be topological spaces and $f : X \to Y$. The function $f$ is Borel measurable if $f : (X, \mathcal{B}(X)) \to (Y, \mathcal{B}(Y))$ is measurable.
:::

::: proposition
Let $X$ and $Y$ be topological spaces and $f : X \to Y$ be continuous. The function $f$ is Borel measurable.
:::

::: proposition
Let $(X, \mathcal{M})$ be a measurable space, $Y$ and $Z$ be topological spaces, $f : X \to Y$ be measurable, and $g : Y \to Z$ be continuous. The composition $g \circ f$ is measurable.
:::

::: proposition
Let $(X, \mathcal{M})$ be a measurable space, $Y$ and $Z$ be topological spaces, $f : X \to Y$ be measurable, and $g : Y \to Z$ be Borel measurable. The composition $g \circ f$ is measurable.
:::

::: proposition
Let $(X, \mathcal{M})$ be a measurable space and $u,v : X \to \mathbb{R}$ be measurable. The functions $\max\{u,v\}$ and $\min\{u,v\}$ are measurable. The positive and negative parts $u^ + := \max\{u,0\}$ and $u^- := \max\{-u,0\}$ are measurable.
:::

::: proposition
Let $(X, \mathcal{M})$ be a measurable space and $u,v : X \to \mathbb{R}$ be measurable. The function $u + iv$ is complex measurable.
:::

::: proposition
Let $(X, \mathcal{M})$ be a measurable space and $f : X \to \mathbb{C}$ be measurable. The functions $\operatorname{Re}f$, $\operatorname{Im}f$, and $|f|$ are real measurable.
:::

::: proposition
Let $(X, \mathcal{M})$ be a measurable space and $f,g : X \to \mathbb{C}$ be measurable. The functions $f + g$ and $fg$ are measurable.
:::

::: proposition
Let $(X, \mathcal{M})$ be a measurable space and $f : X \to \mathbb{C}$ be measurable. There exists a measurable $\alpha : X \to \mathbb{C}$ s.t. $|\alpha| = 1$ and $f = \alpha|f|$.
:::

::: proposition
Let $(X, \mathcal{M})$ be a measurable space and $(f_n)_{n \geq 1}$ be a sequence of nonnegative measurable functions $X \to [0,\infty]$. The pointwise functions $\underset{n \geq 1}{\sup}f_n$ and $\underset{n \to \infty}{\limsup}f_n$ are measurable.
:::

::: proposition
Let $(X, \mathcal{M})$ be a measurable space and $(f_n)_{n \geq 1}$ be a sequence of real or complex measurable functions. If $f_n$ converges pointwise to a real or complex function $f$, then $f$ is measurable.
:::

::: definition:Simple Measurable Function
Let $(X, \mathcal{M})$ be a measurable space. A measurable function $s : X \to \mathbb{C}$ is simple if its range is finite. It can be written as $s = \sum_{j = 1}^m \alpha_j\mathbf{1}_{A_j}$, where the $A_j$ form a finite measurable partition of $X$ and $\mathbf{1}_{A_j}$ is the indicator of $A_j$.
:::

::: proposition
Let $(X, \mathcal{M})$ be a measurable space and $f : X \to [0,\infty]$ be measurable. There exists an increasing sequence $(s_n)_{n \geq 1}$ of nonnegative simple measurable functions s.t. $s_n(x) \to f(x)$ for any $x \in X$.
:::

## Integration
::: definition:Integral of a Nonnegative Function
Let $(X, \mathcal{M}, \mu)$ be a measure space and $E \in \mathcal{M}$. For a nonnegative simple function $s = \sum_{j = 1}^m \alpha_j\mathbf{1}_{A_j}$ on a finite measurable partition, its integral is
$$
\int_E s\,d\mu := \sum_{j = 1}^m \alpha_j\mu(A_j \cap E).
$$
For a nonnegative measurable function $f$, its integral is
$$
\int_E f\,d\mu := \underset{\substack{0 \leq s \leq f\\s\text{ simple measurable}}}{\sup}\int_E s\,d\mu.
$$
The convention $0 \cdot \infty = 0$ is used.
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be a measure space, $f,g : X \to [0,\infty]$ be measurable, $c \geq 0$, and $E \in \mathcal{M}$. The identities $\int_E(f + g)\,d\mu = \int_E f\,d\mu + \int_E g\,d\mu$ and $\int_E cf\,d\mu = c\int_E f\,d\mu$ hold, with $0\cdot\infty = 0$.
:::

::: theorem:Monotone Convergence Theorem
Let $(X, \mathcal{M}, \mu)$ be a measure space and $(f_n)_{n \geq 1}$ be nonnegative measurable functions. Assume $f_n(x) \leq f_{n + 1}(x)$ for any $x \in X$ and $n \geq 1$. Set $f(x) = \underset{n \to \infty}{\lim}f_n(x)$. The integrals satisfy $\underset{n \to \infty}{\lim}\int_X f_n\,d\mu = \int_X f\,d\mu$.
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be a measure space and $(f_n)_{n \geq 1}$ be nonnegative measurable functions. The identity $\int_X \sum_{n = 1}^{\infty} f_n\,d\mu = \sum_{n = 1}^{\infty}\int_X f_n\,d\mu$ holds.
:::

::: note
Nonnegative increasing limits and nonnegative series commute with integration; nonnegativity alone does not justify exchanging an arbitrary pointwise limit with an integral.
:::

::: theorem:Fatou's Lemma
Let $(X, \mathcal{M}, \mu)$ be a measure space and $(f_n)_{n \geq 1}$ be nonnegative measurable functions. The inequality $\int_X \underset{n \to \infty}{\liminf} f_n\,d\mu \leq \underset{n \to \infty}{\liminf}\int_X f_n\,d\mu$ holds.
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be a measure space and $f : X \to [0,\infty]$ be measurable. Set $\phi(E) = \int_E f\,d\mu$ for $E \in \mathcal{M}$. The set function $\phi$ is a measure on $\mathcal{M}$ and $\int_X g\,d\phi = \int_X gf\,d\mu$ for any nonnegative measurable $g$, with $0\cdot\infty = 0$.
:::

::: definition:$L^1$ Space
Let $(X, \mathcal{M}, \mu)$ be a measure space. $L^1(\mu)$ is the collection of equivalence classes, under equality a.e., of complex measurable functions $f$ on $X$ s.t. $\int_X |f| \, d\mu < \infty$.
:::

::: definition:Integral of a Complex Function
Let $(X, \mathcal{M}, \mu)$ be a measure space and $f : X \to \mathbb{C}$ be measurable. Assume $\int_X |f|\,d\mu < \infty$. Set $u = \operatorname{Re}f$ and $v = \operatorname{Im}f$. The integral of $f$ is
$$
\int_X f\,d\mu := \int_X u^ + \,d\mu - \int_X u^-\,d\mu + i\left(\int_X v^ + \,d\mu - \int_X v^-\,d\mu\right).
$$
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be a measure space, $f,g \in L^1(\mu)$, $\alpha,\beta \in \mathbb{C}$, and $E \in \mathcal{M}$. The identities $\int_E(\alpha f + \beta g)\,d\mu = \alpha\int_E f\,d\mu + \beta\int_E g\,d\mu$ and $\left|\int_X f\,d\mu\right| \leq \int_X |f|\,d\mu$ hold. Equality holds in the latter inequality if there exists $\gamma \in \mathbb{C}$ with $|\gamma| = 1$ and $\gamma f = |f|$ a.e.
:::

::: theorem:Dominated Convergence Theorem
Let $(X, \mathcal{M}, \mu)$ be a measure space and $(f_n)_{n \geq 1}$ be complex measurable functions. Assume $f_n \to f$ pointwise and $|f_n| \leq g$ for some nonnegative $g \in L^1(\mu)$ and any $n \geq 1$. The function $f$ belongs to $L^1(\mu)$, $\underset{n \to \infty}{\lim}\int_X f_n\,d\mu = \int_X f\,d\mu$, and $\underset{n \to \infty}{\lim}\int_X |f_n - f|\,d\mu = 0$.
:::

::: note
The same integrable function $g$ must dominate the absolute values of all $f_n$.
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be a measure space and $(f_n)_{n \geq 1}$ be complex measurable functions. Assume $\sum_{n = 1}^{\infty}\int_X |f_n|\,d\mu < \infty$. The series $\sum_{n = 1}^{\infty}f_n$ converges absolutely a.e. Its sum, set to zero on the measurable exceptional set, defines $f \in L^1(\mu)$ s.t. $\int_X f\,d\mu = \sum_{n = 1}^{\infty}\int_X f_n\,d\mu$.
:::

::: note
The summability assumption is equivalent to $\int_X\sum_{n = 1}^{\infty}|f_n|\,d\mu < \infty$ and implies $f_n \in L^1(\mu)$ for each $n$.
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be a measure space, $f : X \to [0,\infty]$ be measurable, and $E \in \mathcal{M}$. If $\int_E f\,d\mu = 0$, then $f = 0$ a.e. on $E$.
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be a measure space and $f \in L^1(\mu)$. If $\int_E f\,d\mu = 0$ for any $E \in \mathcal{M}$, then $f = 0$ a.e. on $X$.
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be a measure space, $f \in L^1(\mu)$, and $S \subseteq \mathbb{C}$ be closed. Assume $\mu(X) < \infty$. Set $A_E(f) = \frac{1}{\mu(E)}\int_E f\,d\mu$ for measurable $E$ with $\mu(E) > 0$. If $A_E(f) \in S$ for every such $E$, then $f(x) \in S$ for almost every $x \in X$.
:::

::: theorem:First Borel–Cantelli Lemma
Let $(X, \mathcal{M}, \mu)$ be a measure space and $(E_n)_{n \geq 1}$ be a sequence in $\mathcal{M}$. If $\sum_{n = 1}^{\infty}\mu(E_n) < \infty$, then almost every $x \in X$ belongs to only finitely many $E_n$.
:::

## Borel Measures
::: definition:Support
Let $X$ be a topological space and $f : X \to \mathbb{C}$. The support of $f$ is $\operatorname{supp}f := \overline{\{x \in X : f(x) \neq 0\}}$.
:::

::: definition:$C_c(X)$
Let $X$ be a topological space. The space $C_c(X)$ consists of continuous functions $f : X \to \mathbb{C}$ with compact support.
:::

::: proposition
Let $X$ be a topological space. The set $C_c(X)$ is a complex vector space, and $f(X)$ is compact for any $f \in C_c(X)$.
:::

::: definition:$K \prec f$
Let $X$ be a topological space, $K \subseteq X$ be compact, and $f \in C_c(X)$. The notation $K \prec f$ means that $f$ is real-valued, $0 \leq f \leq 1$, and $f(x) = 1$ for any $x \in K$.
:::

::: definition:$f \prec V$
Let $X$ be a topological space, $V \subseteq X$ be open, and $f \in C_c(X)$. The notation $f \prec V$ means that $f$ is real-valued, $0 \leq f \leq 1$, and $\operatorname{supp}f \subseteq V$.
:::

::: theorem:Urysohn's Lemma for Locally Compact Hausdorff Spaces
Let $X$ be a locally compact Hausdorff space, $V \subseteq X$ be open, and $K \subseteq X$ be compact. If $K \subseteq V$, then there exists $f \in C_c(X)$ s.t. $K \prec f \prec V$.
:::

::: proposition
Let $X$ be a locally compact Hausdorff space, $V_1,\ldots,V_n \subseteq X$ be open, and $K \subseteq X$ be compact. If $K \subseteq \bigcup_{j = 1}^n V_j$, then there exist $h_j \in C_c(X)$ s.t. $h_j \prec V_j$, $\sum_{j = 1}^n h_j \leq 1$ on $X$, and $\sum_{j = 1}^n h_j = 1$ on $K$.
:::

::: note
The functions $h_j$ above satisfy $K \prec \sum_{j = 1}^n h_j \prec \bigcup_{j = 1}^n V_j$. If $f \in C_c(X)$, $0 \leq f \leq 1$, and $\operatorname{supp}f \subseteq K$, then $f = \sum_{j = 1}^n h_jf$ and $h_jf \prec V_j$.
:::

::: definition:Inner Regular Measure
Let $X$ be a Hausdorff space and $\mu$ be a measure on a $\sigma$-algebra $\mathcal{M}$ containing $\mathcal{B}(X)$. The measure $\mu$ is inner regular if $\mu(E) = \underset{\substack{K \subseteq E\\K\text{ compact}}}{\sup}\mu(K)$ for any $E \in \mathcal{M}$.
:::

::: definition:Outer Regular Measure
Let $X$ be a Hausdorff space and $\mu$ be a measure on a $\sigma$-algebra $\mathcal{M}$ containing $\mathcal{B}(X)$. The measure $\mu$ is outer regular if $\mu(E) = \underset{\substack{E \subseteq V\\V\text{ open}}}{\inf}\mu(V)$ for any $E \in \mathcal{M}$.
:::

::: definition:Regular Measure
Let $X$ be a Hausdorff space and $\mu$ be a measure on a $\sigma$-algebra $\mathcal{M}$ containing $\mathcal{B}(X)$. The measure $\mu$ is regular if it is both inner regular and outer regular.
:::

::: theorem:Riesz Representation Theorem
Let $X$ be a locally compact Hausdorff space and $\Lambda : C_c(X) \to \mathbb{C}$ be a linear functional. Assume $\Lambda(f) \geq 0$ for every real-valued $f \in C_c(X)$ with $f \geq 0$. There exist a $\sigma$-algebra $\mathcal{M} \supseteq \mathcal{B}(X)$ and a unique measure $\mu$ on $\mathcal{M}$ with the following properties.
The representation $\Lambda(f) = \int_X f\,d\mu$ holds for any $f \in C_c(X)$, and $\mu(K) < \infty$ for any compact $K \subseteq X$.
The measure is outer regular on $\mathcal{M}$ and satisfies $\mu(E) = \underset{\substack{K \subseteq E\\K\text{ compact}}}{\sup}\mu(K)$ whenever $E$ is open or $E \in \mathcal{M}$ has finite measure.
The measure space is complete: if $E \in \mathcal{M}$, $\mu(E) = 0$, and $A \subseteq E$, then $A \in \mathcal{M}$.
::: ^positive-riesz-representation

::: proposition
Let $(X, \mathcal{M}, \mu)$ be as in [[#^positive-riesz-representation|the Riesz representation theorem]] and $E \in \mathcal{M}$. Assume $X$ is $\sigma$-compact. The measure $\mu$ is regular. For any $\epsilon > 0$, there exist a closed set $F$ and an open set $V$ s.t. $F \subseteq E \subseteq V$ and $\mu(V\setminus F) < \epsilon$. There also exist an $F_\sigma$ set $A$ and a $G_\delta$ set $B$ s.t. $A \subseteq E \subseteq B$ and $\mu(B\setminus A) = 0$.
:::

::: proposition
Let $X$ be a locally compact Hausdorff space and $\lambda$ be a Borel measure on $X$. Assume every open subset of $X$ is $\sigma$-compact and $\lambda(K) < \infty$ for every compact $K \subseteq X$. The measure $\lambda$ is regular on $\mathcal{B}(X)$.
:::

::: theorem:Lebesgue Measure
Let $k \geq 1$ be an integer. There exists a complete regular measure $m$ on a $\sigma$-algebra $\mathcal{M} \supseteq \mathcal{B}(\mathbb{R}^k)$ with the following properties.
For any bounded rectangle $W = \prod_{j = 1}^k(a_j,b_j)$, its measure is $m(W) = \prod_{j = 1}^k(b_j - a_j)$; the same formula holds if any endpoints are included.
A set $E \subseteq \mathbb{R}^k$ belongs to $\mathcal{M}$ iff there exist an $F_\sigma$ set $A$ and a $G_\delta$ set $B$ s.t. $A \subseteq E \subseteq B$ and $m(B\setminus A) = 0$.
Translation invariance holds: $E + x \in \mathcal{M}$ and $m(E + x) = m(E)$ for any $E \in \mathcal{M}$ and $x \in \mathbb{R}^k$.
If $\nu$ is a translation-invariant Borel measure finite on compact sets, then there exists $c \geq 0$ s.t. $\nu = cm$ on Borel sets.
For any linear map $T : \mathbb{R}^k \to \mathbb{R}^k$ and $E \in \mathcal{M}$, the set $T(E)$ is measurable and $m(T(E)) = |\det T|m(E)$, with $0\cdot\infty = 0$.
:::

::: proposition
Let $k \geq 1$ be an integer, $m$ be Lebesgue measure on $\mathbb{R}^k$, and $E \subseteq \mathbb{R}^k$ be Lebesgue measurable. If $m(E) > 0$, then $E$ contains a non-Lebesgue-measurable subset.
:::

::: theorem:Lusin's Theorem
Let $(X, \mathcal{M}, \mu)$ be as in [[#^positive-riesz-representation|the Riesz representation theorem]], $f$ be a complex measurable function, $A \in \mathcal{M}$, and $\epsilon > 0$. Assume $f(x) = 0$ for $x \notin A$ and $\mu(A) < \infty$. There exists $g \in C_c(X)$ s.t. $\mu(\{x : f(x) \neq g(x)\}) < \epsilon$ and $\underset{x \in X}{\sup} |g(x)| \leq \underset{x \in X}{\sup} |f(x)|$.
:::

::: corollary
Let $(X, \mathcal{M}, \mu)$ be as in [[#^positive-riesz-representation|the Riesz representation theorem]] and $f : X \to \mathbb{C}$ be measurable. Assume $|f| \leq 1$ and $f = 0$ outside a measurable set of finite measure. There exists a sequence $(g_n)_{n \geq 1}$ in $C_c(X)$ s.t. $|g_n| \leq 1$ and $g_n \to f$ a.e.
:::

::: theorem:Vitali–Carathéodory Theorem
Let $(X, \mathcal{M}, \mu)$ be as in [[#^positive-riesz-representation|the Riesz representation theorem]], $f \in L^1(\mu)$ be a real function, and $\epsilon > 0$. There exist functions $u$ and $v$ s.t. $u \leq f \leq v$, $u$ is upper semicontinuous and bounded above, $v$ is lower semicontinuous and bounded below, and $\int_X (v - u) \, d\mu < \epsilon$.
:::

## Lp Spaces
::: definition:Convex Function
Let $-\infty \leq a < b \leq \infty$ and $\phi : (a,b) \to \mathbb{R}$. The function $\phi$ is convex if $\phi((1 - \lambda)x + \lambda y) \leq (1 - \lambda)\phi(x) + \lambda\phi(y)$ for any $x,y \in (a,b)$ and $\lambda \in [0,1]$. Equivalently, the secant slopes satisfy $\frac{\phi(t) - \phi(s)}{t - s} \leq \frac{\phi(u) - \phi(t)}{u - t}$ for any $a < s < t < u < b$.
:::

::: proposition
Let $\phi : (a,b) \to \mathbb{R}$ be convex. The function $\phi$ is continuous on $(a,b)$.
:::

::: theorem:Jensen's Inequality
Let $(\Omega,\mathcal{M},\mu)$ be a probability space, $f \in L^1(\mu)$ be real-valued, and $\phi : (a,b) \to \mathbb{R}$ be convex. Assume $f(x) \in (a,b)$ for any $x \in \Omega$. The inequality $\phi(\int_\Omega f\,d\mu) \leq \int_\Omega \phi(f)\,d\mu$ holds, with the right-hand side allowed to equal $ + \infty$.
:::

::: proposition
Let $x_1,\ldots,x_n > 0$ and $a_1,\ldots,a_n \geq 0$. Assume $\sum_{j = 1}^n a_j = 1$. The inequality $\prod_{j = 1}^n x_j^{a_j} \leq \sum_{j = 1}^n a_jx_j$ holds. In particular, $(\prod_{j = 1}^n x_j)^{\frac{1}{n}} \leq \frac{1}{n}\sum_{j = 1}^n x_j$.
:::

::: proposition
Let $(\Omega,\mathcal{M},\mu)$ be a probability space and $g : \Omega \to (0,\infty)$ be measurable. Assume $g \in L^1(\mu)$. The inequality $\exp(\int_\Omega\log g\,d\mu) \leq \int_\Omega g\,d\mu$ holds, with $\exp(-\infty) = 0$.
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be a measure space, $f,g : X \to [0,\infty]$ be measurable, and $1 < p,q < \infty$. Assume $\frac{1}{p} + \frac{1}{q} = 1$. The inequality $\int_X fg\,d\mu \leq (\int_X f^p\,d\mu)^{\frac{1}{p}}(\int_X g^q\,d\mu)^{\frac{1}{q}}$ holds in the extended nonnegative reals, with $0\cdot\infty = 0$.
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be a measure space, $f,g : X \to [0,\infty]$ be measurable, and $1 < p < \infty$. The inequality $(\int_X(f + g)^p\,d\mu)^{\frac{1}{p}} \leq (\int_X f^p\,d\mu)^{\frac{1}{p}} + (\int_X g^p\,d\mu)^{\frac{1}{p}}$ holds, allowing infinite integrals.
:::

::: definition:Essential Supremum
Let $(X, \mathcal{M}, \mu)$ be a measure space and $f : X \to [0,\infty]$ be measurable. The essential supremum is $\operatorname{ess\,sup}_X f := \underset{\substack{c \in [0,\infty)\\\mu(\{x:f(x) > c\}) = 0}}{\inf}c$, with $\inf\emptyset = \infty$.
:::

::: definition:$L^p$ Norm and Quasi-Norm
Let $(X, \mathcal{M}, \mu)$ be a measure space and $f : X \to \mathbb{C}$ be measurable. The quantities $\|f\|_p := (\int_X |f|^p\,d\mu)^{\frac{1}{p}}$ for $0 < p < \infty$ and $\|f\|_\infty := \operatorname{ess\,sup}_X|f|$ are invariant under equality a.e. On equivalence classes with finite value, they define a norm for $1 \leq p \leq \infty$ and a quasi-norm for $0 < p < 1$.
:::

::: definition:$L^p$ Space
Let $(X, \mathcal{M}, \mu)$ be a measure space and $0 < p \leq \infty$. The space $L^p(\mu)$ consists of equivalence classes of measurable $f : X \to \mathbb{C}$ with $\|f\|_p < \infty$, where functions equal a.e. are identified.
:::

::: theorem:Hölder's Inequality
Let $(X, \mathcal{M}, \mu)$ be a measure space, $p,q \in [1,\infty]$, $f \in L^p(\mu)$, and $g \in L^q(\mu)$. Assume $\frac{1}{p} + \frac{1}{q} = 1$, with $\frac{1}{\infty} = 0$. The product $fg$ belongs to $L^1(\mu)$ and $\|fg\|_1 \leq \|f\|_p\|g\|_q$. If $1 < p < \infty$ and $\alpha|f|^p = \beta|g|^q$ a.e. for some $\alpha,\beta \geq 0$ not both zero, then equality holds.
:::

::: theorem:Minkowski's Inequality
Let $(X, \mathcal{M}, \mu)$ be a measure space, $1 \leq p \leq \infty$, and $f,g \in L^p(\mu)$. The sum $f + g$ belongs to $L^p(\mu)$ and $\|f + g\|_p \leq \|f\|_p + \|g\|_p$. If $f = \lambda g$ a.e. for some $\lambda > 0$, then equality holds.
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be a measure space, $1 \leq p \leq \infty$, $f \in L^p(\mu)$, and $\alpha \in \mathbb{C}$. The function $\alpha f$ belongs to $L^p(\mu)$ and $\|\alpha f\|_p = |\alpha|\|f\|_p$.
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be a measure space and $1 \leq p \leq \infty$. The space $L^p(\mu)$ is a Banach space under $\|\cdot\|_p$.
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be a measure space and $1 \leq p < \infty$. Set $S$ to be the space of complex simple measurable functions $s$ with $\mu(\{x:s(x) \neq 0\}) < \infty$. The space $S$ is dense in $L^p(\mu)$.
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be as in [[#^positive-riesz-representation|the Riesz representation theorem]] and $1 \leq p < \infty$. The space $C_c(X)$ is dense in $L^p(\mu)$.
:::

::: definition:$C_0(X)$
Let $X$ be a locally compact Hausdorff space. The space $C_0(X)$ consists of continuous functions $f : X \to \mathbb{C}$ that vanish at infinity: $\{x \in X:|f(x)| \geq \epsilon\}$ is compact for any $\epsilon > 0$.
:::

::: proposition
Let $X$ be a locally compact Hausdorff space. Under the uniform norm $\|f\|_{\mathrm{sup}} := \underset{x \in X}{\sup}|f(x)|$, the space $C_0(X)$ is the completion of $C_c(X)$.
:::

::: proposition
Let $(X, \mathcal{M}, \mu)$ be a measure space. The space $L^2(\mu)$ is a Hilbert space with inner product $\langle f,g\rangle = \int_X\overline f g\,d\mu$.
:::

::: proposition
Let $A$ be a countable set and $\mu$ be counting measure on $\mathcal{P}(A)$. The space $L^2(A,\mu)$ is naturally identified with [[#^ell2-indexed-families|$\ell^2(A)$]].
:::

## Orthonormal Expansions
::: definition:Orthonormal Set
Let $V$ be an inner product space and $(u_\alpha)_{\alpha \in A}$ be a family in $V$. The family is orthonormal if $\|u_\alpha\| = 1$ for any $\alpha \in A$ and $\langle u_\alpha,u_\beta\rangle = 0$ whenever $\alpha \neq \beta$.
:::

::: definition:Maximal Orthonormal Set
Let $H$ be a Hilbert space and $B \subseteq H$ be orthonormal. The set $B$ is maximal orthonormal if no proper superset of $B$ in $H$ is orthonormal.
:::

::: definition:$\ell^2(A)$
Let $A$ be a set and $\mathbb{F} \in \{\mathbb{R},\mathbb{C}\}$. The space $\ell^2(A;\mathbb{F})$ consists of families $z = (z_\alpha)_{\alpha \in A}$ with $z_\alpha \in \mathbb{F}$ s.t. $\sum_{\alpha \in A}|z_\alpha|^2 < \infty$, where
$$
\sum_{\alpha \in A}|z_\alpha|^2 := \underset{\substack{F \subseteq A\\F\text{ finite}}}{\sup}\sum_{\alpha \in F}|z_\alpha|^2.
$$
Its norm is $\|z\|_2 = (\sum_{\alpha \in A}|z_\alpha|^2)^{\frac{1}{2}}$ and its inner product is $\langle z,w\rangle = \sum_{\alpha \in A}\overline{z_\alpha}w_\alpha$. The notation $\ell^2(A)$ suppresses the scalar field when it is understood.
::: ^ell2-indexed-families

::: proposition
Let $A$ be a set and $\mathbb{F} \in \{\mathbb{R},\mathbb{C}\}$. Every element of $\ell^2(A;\mathbb{F})$ has at most countably many nonzero coordinates. The sum defining $\langle z,w\rangle$ is absolutely convergent for any $z,w \in \ell^2(A;\mathbb{F})$, and $\ell^2(A;\mathbb{F})$ is a Hilbert space under this inner product.
:::

::: definition:Unconditional Sum
Let $V$ be a normed vector space, $(v_\alpha)_{\alpha \in A}$ be a family in $V$, and $v \in V$. The sum $\sum_{\alpha \in A}v_\alpha$ converges unconditionally in norm to $v$ if, for any $\varepsilon > 0$, there exists a finite set $F_0 \subseteq A$ s.t. $\|v - \sum_{\alpha \in F}v_\alpha\| < \varepsilon$ for every finite set $F \subseteq A$ containing $F_0$. In this case, write $v = \sum_{\alpha \in A}v_\alpha$.
:::

::: theorem:Bessel's Inequality
Let $H$ be a Hilbert space over $\mathbb{F}$ and $(u_\alpha)_{\alpha \in A}$ be an orthonormal family. Set $\hat{x}(\alpha) = \langle u_\alpha,x\rangle$ for $x \in H$. The inequality $\sum_{\alpha \in A}|\hat{x}(\alpha)|^2 \leq \|x\|^2$ holds for any $x \in H$.
:::

::: theorem:Riesz–Fischer Theorem
Let $H$ be a Hilbert space over $\mathbb{F}$ and $(u_\alpha)_{\alpha \in A}$ be an orthonormal family. Set $M = \overline{\operatorname{span}}\{u_\alpha : \alpha \in A\}$. For any $z \in \ell^2(A;\mathbb{F})$, the sum $\sum_{\alpha \in A}z_\alpha u_\alpha$ converges unconditionally in norm to the unique $x \in M$ satisfying $\langle u_\alpha,x\rangle = z_\alpha$ for any $\alpha \in A$. The coefficient map $x \mapsto (\langle u_\alpha,x\rangle)_{\alpha \in A}$ is a surjective linear isometry from $M$ onto $\ell^2(A;\mathbb{F})$.
:::

::: proposition
Let $H$ be a Hilbert space and $(u_\alpha)_{\alpha \in A}$ be an orthonormal family. Set $M = \overline{\operatorname{span}}\{u_\alpha : \alpha \in A\}$. Denote the orthogonal projection onto $M$ by $P_M$. The expansion
$$
P_Mx = \sum_{\alpha \in A}\langle u_\alpha,x\rangle u_\alpha
$$
converges unconditionally in norm for any $x \in H$, and
$$
\|x - P_Mx\|^2 = \|x\|^2 - \sum_{\alpha \in A}|\langle u_\alpha,x\rangle|^2.
$$
:::

::: definition:Orthonormal Basis
Let $H$ be a Hilbert space and $(u_\alpha)_{\alpha \in A}$ be an orthonormal family. The family is an orthonormal basis of $H$ if $\overline{\operatorname{span}}\{u_\alpha : \alpha \in A\} = H$.
:::

::: proposition
Let $H$ be a Hilbert space and $(u_\alpha)_{\alpha \in A}$ be an orthonormal family. Set $\hat{x}(\alpha) = \langle u_\alpha,x\rangle$ for $x \in H$. The following conditions are equivalent: the family is maximal orthonormal; it is an orthonormal basis of $H$; $x = \sum_{\alpha \in A}\hat{x}(\alpha)u_\alpha$ with unconditional convergence in norm for any $x \in H$; $\sum_{\alpha \in A}|\hat{x}(\alpha)|^2 = \|x\|^2$ for any $x \in H$; and $\sum_{\alpha \in A}\overline{\hat{x}(\alpha)}\hat{y}(\alpha) = \langle x,y\rangle$ for any $x,y \in H$. The last equality is Parseval's identity.
:::

::: definition:Partially Ordered Set
Let $P$ be a set and $\leq$ be a relation on $P$. The pair $(P,\leq)$ is a partially ordered set if:
- $a \leq a$ for any $a \in P$.
- If $a \leq b$ and $b \leq a$, then $a = b$.
- If $a \leq b$ and $b \leq c$, then $a \leq c$.
Here $a,b,c$ range over $P$. A chain is a subset whose elements are pairwise comparable.
:::

::: theorem:Hausdorff's Maximality Principle
Let $P$ be a nonempty partially ordered set. There exists a chain in $P$ maximal under inclusion.
:::

::: proposition
Let $H$ be a Hilbert space and $B \subseteq H$ be orthonormal. There exists a maximal orthonormal set in $H$ containing $B$.
:::

::: definition:Hilbert Space Isomorphism
Let $H_1$ and $H_2$ be Hilbert spaces over the same field and $U : H_1 \to H_2$ be linear. The map $U$ is a Hilbert space isomorphism if it is surjective and $\langle Ux,Uy\rangle = \langle x,y\rangle$ for any $x,y \in H_1$.
:::

::: corollary
Let $H$ be a Hilbert space over $\mathbb{F}$. There exists an orthonormal basis $(u_\alpha)_{\alpha \in A}$ of $H$. For any such basis, the coefficient map
$$
U : H \to \ell^2(A;\mathbb{F}), \qquad Ux = (\langle u_\alpha,x\rangle)_{\alpha \in A}
$$
is a Hilbert space isomorphism, with inverse
$$
U^{-1}z = \sum_{\alpha \in A}z_\alpha u_\alpha,
$$
where the sum converges unconditionally in norm.
:::

## Fourier Series
::: definition:$L^p(T)$
Let $T = \mathbb{R}/(2\pi\mathbb{Z})$ be the circle and $1 \leq p \leq \infty$. The space $L^p(T)$ is defined using normalized Lebesgue measure $d\mu = \frac{1}{2\pi}\,dt$ on one period. Its elements are equivalence classes of $2\pi$-periodic measurable functions with finite $L^p$ norm. The notation $C(T)$ denotes the continuous $2\pi$-periodic complex functions.
:::

::: definition:Trigonometric Polynomial
A trigonometric polynomial is a function $P(t) = \sum_{n = -N}^N c_ne^{int}$ for some integer $N \geq 0$ and coefficients $c_n \in \mathbb{C}$.
:::

::: proposition
Let $f \in C(T)$ and $\epsilon > 0$. There exists a trigonometric polynomial $P$ s.t. $\underset{t \in T}{\sup}|f(t) - P(t)| < \epsilon$.
:::

::: definition:Fourier Coefficient
Let $f \in L^1(T)$. The Fourier coefficient of $f$ is $\hat{f}(n) = \frac{1}{2\pi} \int_{-\pi}^{\pi} f(t) e^{-int} \, dt$ for $n \in \mathbb{Z}$.
:::

::: definition:Fourier Series
Let $f \in L^1(T)$. The Fourier series of $f$ is the formal series $\sum_{n = -\infty}^{\infty} \hat{f}(n) e^{int}$.
:::

::: definition:Fourier Partial Sum
Let $f \in L^1(T)$ and $N \geq 0$ be an integer. The Fourier partial sum of $f$ is $\sum_{n = -N}^{N} \hat{f}(n) e^{int}$.
:::

::: note
Together with the density of $C(T)$ in $L^2(T)$, this approximation result makes the trigonometric polynomials dense in $L^2(T)$. Thus $(e^{int})_{n \in \mathbb{Z}}$ is a complete orthonormal family for normalized Lebesgue measure, and the Fourier partial sums of each $f \in L^2(T)$ converge to $f$ in $L^2$ norm.
:::
